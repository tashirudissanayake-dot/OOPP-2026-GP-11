﻿# Faculty of Technology Management System (FoT-TMS)
**Mini-Project: ICT2132 - Object Oriented Programming Practicum**
**Group: G11**

## Prerequisites
- Java JDK 17 or higher
- MySQL Database (XAMPP / MySQL Server on port 3306)

## Setup Instructions
1. Start MySQL service in XAMPP.
2. Import database script located at database/fot_tms_db.sql
3. Double-click run.bat to launch the application.
